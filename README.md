# Roadmap & Agenda for an Ideological Manifesto

**This is not software.** This repository does not contain code libraries, tools, or anything aimed at programmers.

It is a **website** — a roadmap and agenda for an ideological manifesto about the constructive path toward a modern society without scarcity.

If you are a programmer looking for something useful here, the only exception is:

- `tropics/tropics.html` — a tropical globe (if you happen to need one).

Everything else is text, ideas, and structure for a manifesto in progress.
