Så här får du det att fungera:

  1. Se till att lang/js/lang.js på GitHub är denna fil:
    varldsmanifestet-FINAL-COMPLETE-with-localStorage-PD.js (med gl:es och sv-ax:sv fixarna)
  2. Om din lang.html ligger i root, använd:
    from './lang/js/lang.js'
  3. Om din lang.html ligger i lang/ mappen, använd:
    from './js/lang.js'
  4. Byt till <script type="module"> - annars funkar inte import

Testa i konsolen: öppna Developer Tools (F12) och skriv
navigator.languages = ['ca'] sedan ladda om - då ska den föreslå es
